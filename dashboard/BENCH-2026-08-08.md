# Bench block, 2026-08-08

The recordings that survived the day's triage: the two rest tracks, a five-atom
track, and the thumb-modifier block. Superset, chords and intensity were
recorded or ruled out on this bench day and their configs and tracks are gone;
engineering log 0022 holds the measurements.

## Before anything

The collection config is read once, at startup. A block that needs different
lanes needs its own backend run.

```
cd dashboard
./run.sh                                                      # rest + five atoms
EMG_COLLECTION_CONFIG=config/collection-modifier.json ./run.sh # modifier block
```

Confirm at the start of each run that the lane count in the game matches the
block: five for both configs here, so check the lane labels too — the modifier
lanes all name the thumb. If they do not, the old backend still holds :8090.

## Order

| # | Track | Config | Length | Reps |
|---|---|---|---|---|
| 1 | `rest-static` | default | 3.0 min | no cues |
| 2 | `rest-moving` | default | 3.0 min | no cues, click paces the swing |
| 3 | `acloudyskye-flares` | default | 3.8 min | 16 per class |
| 4 | `modifier-a` | modifier | 4.3 min | 10 per class, 1.4 s holds |

Rest comes first because a rest span is only worth having while the skin is
fresh. Any five-atom track substitutes for item 3; `acloudyskye-flares` gets
the most reps per minute without running long.

## Between every item

Re-seat the band and enter the new geometry in the setup form before starting —
unless the item exists to be a same-don pair with its neighbour (a thumb-down
control right after the modifier block), in which case do not touch the band
and say so in the session note.

1. Lift the band clear, wipe the skin, re-seat it.
2. Set band offset and rotation in the form to what you just placed.
3. Press re-donned so the timestamp moves.
4. Check the electrode panel before pressing start; a channel that is flat or
   railed is worth fixing now rather than at analysis.

## The modifier block

The four wrist motions are the same ones already collected against
collection.json — the thumb is the only difference, and it is what the model
has to find. Say it before the first cue and again if the hand relaxes: the
thumb comes up out of the grip and stays extended for the whole hold, not just
the onset. Tip forward, tip back, tip in and tip out are unchanged at the
wrist. The fifth lane, thumb up hold, is the extended thumb on its own, held
with the wrist still. It carries no arrow, so read it out the first time it
comes round.

## Regenerating the tracks

`python3 scripts/make_experiment_tracks.py` rewrites `modifier-a`,
`python3 scripts/make_rest_tracks.py` the two rest tracks, and
`python3 scripts/check_experiment_tracks.py` validates against what the
backend's loader demands. None of them touch the imported music.
